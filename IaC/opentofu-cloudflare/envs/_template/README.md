# Cloudflare stack (OpenTofu)

Managed by the OpenSible Cloud Provisioning wizard.

## What this stack provisions

- DNS zone (create or reference existing)
- DNS records (A / AAAA / CNAME / TXT / MX / …)
- R2 object-storage buckets
- Worker scripts + zone routes
- Zero Trust Access applications + allow-email policies

## Files

- `variables.tf` — input schema
- `main.tf` — resources
- `providers.tf` / `versions.tf` — Cloudflare provider pin (`~> 4.52`)
- `terraform.tfvars` — generated by the wizard
- `credentials.auto.tfvars` — API token, chmod 600, never committed
- `backend.tf` — local state by default

## Manual run

```sh
tofu init
tofu plan
tofu apply
```
