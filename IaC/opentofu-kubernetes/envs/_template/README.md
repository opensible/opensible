# Kubernetes stack (OpenTofu)

Managed by the OpenSible Cloud Provisioning wizard — **Mode A "Bring your own cluster"**.

## What this stack provisions (into an existing cluster)

- Namespace (create or assume-exists)
- Workloads: `Deployment` + `Service` per entry
- Optional `Ingress` (single, in front of one workload's service)
- Optional Helm addons: ingress-nginx, cert-manager, metrics-server

## Files

- `variables.tf` — input schema
- `main.tf` — Kubernetes + Helm resources
- `providers.tf` / `versions.tf` — kubernetes ~> 2.30, helm ~> 2.13
- `terraform.tfvars` — generated by the wizard
- `credentials.auto.tfvars` — bearer-token/CA when `auth_method="token"`
- `kubeconfig.yaml` — materialised from the encrypted secret at run time (chmod 600) when `auth_method="kubeconfig"`
- `backend.tf` — local state by default

## Manual run

```sh
tofu init
tofu plan
tofu apply
```
